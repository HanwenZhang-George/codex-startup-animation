Repair scope
- R13 cold-target discovery increases a subsequent fresh idempotent read's
  response allowance from 2 to 4 seconds after a response timeout. The total
  horizon remains 30 seconds. Attachment is sent once, capped at 12 seconds and
  remaining time. Mutations are not retried; stale request replies are rejected.
- Previously verified ownership of the initially hidden window is preserved
  when additional hidden auxiliary windows appear. Enumeration, process,
  ownership and recovery checks remain; ambiguous unowned targets are untouched.
- Earlier R11/R12 changes admit a narrowly verified official page-surface shell,
  revalidate style bindings after supported shell attribute/remount changes,
  resolve optional shortcut entries through the registered manifest, and allow
  one bounded rediscovery for a registration transition without bypassing trust.
- Repeated launch can restore the same verified target when it was already
  minimized at selection, with bounded nonactivating recovery and compensation;
  later user minimization is respected.
- Diagnostics retain bounded per-attempt evidence and distinguish public-entry
  failures, old playback evidence, transport/target loss and process exit.
  Exit code zero alone does not establish a voluntary user exit.
- R10 automatic official version/path discovery and R9 commit-headroom recovery
  remain. Below 512 MiB available commit pauses decoding; at least 1 GiB stable
  for 30 seconds permits a recovery request. Requesting recovery is not proof
  of resumed playback. Existing identity and resource protections remain.

Support and privacy
- Run Diagnostics/One-Click-Diagnostics.cmd in the actual running copy.
  Outputs: Diagnostics/Reports/latest-analysis.txt and latest-report.zip.
- The one-click Detailed mode verifies all formal file hashes, then collects
  bounded diagnostic records and numeric environment evidence. It attempts to
  produce the report even when file verification identifies damage.
- Check-All-Files.cmd checks files alone. Run-Diagnostics.ps1 -Mode Report is
  the optional quick mode without a new full-file hash pass.
- Tools do not launch/close/wait for apps, install dependencies, access the
  network, decode video or run CPU/GPU stress tests. Full hashing reads media
  files; slow disks/security scanning can extend the collection time.
- Only the latest output report is retained; copy it elsewhere before retrying
  if preserving an earlier failure. Logs and exported records are bounded.
- No raw DOM, paths, titles, chat, account configurations, command lines or API
  keys are intended report fields. Do not submit raw logs or entire directories.
- User tutorial and authorized contact addresses are in TROUBLESHOOTING.md.

Supported boundary
- Windows 10/11 x64, .NET Framework 4.8+, Windows PowerShell 5.1, a writable local
  NTFS directory and working Windows media components are required.
- Wallpaper transport supports the verified official Microsoft Store Codex
  Electron private CDP pipe. Tauri/Wry/WebView2 transport is not implemented.
  WebView2 markers alone do not establish runtime identity or support.
- Ordinary official version/manifest-entry path updates can be rediscovered.
  Package identity, signer, framework, protocol or DOM changes can still need
  maintenance; universal future compatibility is not claimed.
- An ordinary already-running client without the managed host cannot safely
  be retrofitted. Save work, exit normally, then use this Launch.exe.
- No public debugging TCP port is enabled. File integrity and isolated tests
  do not prove real decoding, rendering performance or long-term reliability
  on every computer. User-reported success is preserved as separate evidence.
- Optional Install-and-Bind.cmd is a reversible per-user shortcut operation.
  Normal launch does not require recurring administrator authorization.
- The public package contains Codex startup animation and wallpaper, no CC
  Switch, personal account data or conversation records. Upstream attribution
  and font license remain; no new third-party media/code license is invented.
