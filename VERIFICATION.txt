Fix scope
- Bound native hide acknowledgement to 3 seconds, with at most six requests
  spaced at least 500 ms apart. Only an observed hidden state advances.
  Preserve identity/ownership checks and the current minimized state.
- Order nonactivating show compensation after queued hide requests on both
  successful placement and failed preparation. Isolated real-window fixtures
  reproduced the old re-show race and late-hide failures.
- Once the current operation/document/media is prepared, refresh read-only
  state instead of sending repeated preparation commands during the finale.
- Reconcile only an eligible prepare-response timeout with fresh matching
  state before its original deadline. Do not replay the mutation or weaken
  commit, protocol, transport, identity or cancellation checks.
- Retain preceding readiness-transport and composer/footer transparency fixes,
  and bounded numeric diagnostics for native readiness and request failures.

Compatibility and limits
- Windows 10/11 x64, .NET Framework 4.8+, Windows PowerShell 5.1, working Windows
  media components, and the current user's official Microsoft Store Codex x64
  are required. Windows N may need Media Feature Pack.
- Use Launch.exe from a fully extracted local writable directory. This public
  package does not replace the official icon or copy personal installation hooks.
- No CC Switch integration is included. Existing account configuration and
  conversations are not part of the package.
- Community EXEs are not commercially signed. Do not disable Windows security.
- The observed long wait is fixed on the tested paths; this is not a universal
  startup-duration guarantee. The underlying reason the reported target did
  not acknowledge its first hide cannot be uniquely established from logs.
- Future Codex/Windows changes, all GPUs, 24/48-hour or ten-day stability and
  full host/renderer crash isolation are not certified by this release.
- No upstream code license was found. Existing attribution and font OFL are
  retained; no new license is imposed on upstream code or media.
