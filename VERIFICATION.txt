R9 repair scope
- A Windows low-physical-memory notification alone no longer permanently
  disables wallpaper preparation. Critical process-available commit below
  512 MiB pauses decoding; recovery requires at least 1 GiB for the existing
  continuous 30-second hold. This is commit headroom, not free physical RAM.
- A paused attach retains its File without allocating the Blob/decoder.
  Recovery retains the same document and validated File attachment; each
  decoder wake uses a fresh media generation and fresh frame evidence.
- Fresh authenticated host-only pressure can release the startup cover even
  when the launcher's independent pressure sample missed that short signal.
- Startup self-resource limits, signed client/path identity, private pipe,
  lease/generation checks and explicit pause/disable semantics remain.
- Diagnostics distinguish legacy terminal error 174, reversible suspension,
  recovery requests and actual first-frame evidence.
- Earlier native handoff, window transparency and warm-launch fixes remain.

Support and privacy
- Run Diagnostics/One-Click-Diagnostics.cmd in the actual running copy.
  Fixed outputs: Diagnostics/Reports/latest-analysis.txt and latest-report.zip.
- Check-All-Files.cmd optionally verifies all formal file hashes; collect
  diagnostics again afterward to include its bounded verification summary.
- These support tools neither launch/close/wait for apps nor run CPU/GPU
  stress tests, download dependencies or upload anything automatically.
- Only allowlisted bounded diagnostic fields are exported. Do not submit
  raw logs, credentials, private keys, browser profiles or conversation data.
- Full instructions and explicitly authorized contact addresses are in
  TROUBLESHOOTING.md. Public commits use a GitHub noreply author address.

Supported boundary
- Windows 10/11 x64, .NET Framework 4.8+, Windows PowerShell 5.1, local writable
  NTFS directory and working Windows media components are required.
- Wallpaper transport supports the verified official Microsoft Store Codex
  Electron private CDP pipe. Tauri/Wry/WebView2 transport is not implemented.
  Seeing WebView2 files alone does not establish a client's runtime identity.
- Existing ordinary Codex sessions without the managed wallpaper host cannot
  safely be retrofitted. Save work, exit normally, then use this Launch.exe.
- No public debug port is enabled; unsupported clients fail safely.
- File integrity does not prove decoding or UI performance on every device.
- Launch.exe runs as a normal user. Optional Install-and-Bind.cmd is separate;
  it attempts a reversible binding to one trusted existing desktop shortcut.
- The author's stable Codex/CC Switch installations were not changed for this
  publication. Public distribution includes no CC Switch or account settings.
- Upstream attribution and existing font license are retained; this project
  does not grant new rights to third-party code or media.
