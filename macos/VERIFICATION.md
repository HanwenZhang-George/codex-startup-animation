# Mac 验证记录

验证日期：2026-11-10。测试平台：Apple Silicon，macOS 26.6.2，Swift 6.4；官方客户端 bundle ID 为 com.openai.codex，版本系列 157。

2026-11-11 提交前复核：通用原生 bundle 构建、双架构／签名检查与无客户端媒体解码通过；新增新版 Mac 独立类名回归 15 项断言，加上原有 277 项，共 292 项离线渲染断言通过。浏览器内显式区分普通透明度与“减少透明度”，验证 60% 玻璃效果和不透明的无障碍回退，不依赖 CI 主机的偏好。Dock 绑定测试改用临时应用元数据，在独立偏好域验证重复绑定、位置保留及还原，不需要安装官方客户端。此次复核未运行图形预览或启动官方客户端集成测试；下面的实际播放与管道集成记录来自 2026-11-10。

已通过：

- 1.1.0 新增：缺失视频、损坏配置、动画启动器缺失、动画启动器退出的实际应用回退检查通过。独立 Dock 入口使用原图标并保留官方应用；普通启动兜底限时五秒触发，不能保证操作系统或官方应用自身故障时仍成功。
- 1.1.0 新增：安装后的 ChatGPT 入口实际打开启动动画、确认首帧呈现并成功交接至官方应用。Dock 绑定／重复绑定／还原保持图标位置和其他条目，并保留后续对其他条目的修改；通过专用测试偏好域验证。绑定后读取系统偏好，确认 Dock 的 ChatGPT 指向用户 Applications 中的新入口。

- 六段原始 MP4 与 R16 发布包分别通过 SHA-256 校验，未重新编码。
- 原生预览实际解码并呈现首帧，播放流泪片段后退出。
- 原生启动实际交接到已运行的官方应用，不关闭已有会话。
- arm64、x86_64 两架构编译通过；Info.plist 与临时代码签名验证通过。
- 配置默认值、非法 JSON、非法目标、带空格应用路径及配置读写通过。
- Mac 渲染器离线回归：ShellRoutes 163、AsyncLifecycle 28、Transitions 40、MediaCycles 46，共 277 项断言通过。
- 官方 Mac 客户端隔离实例：私有管道回应、app:// 页面绑定、新式类名校验、实际壁纸首帧、两段媒体可用、暂停、恢复原界面通过。
- 完整 Mac 管道助手隔离实例：提前发送跳过请求后仍能显示壁纸；暂停／继续、恢复／重新启用、关闭启动器后仍保留官方客户端通过。

官方客户端的集成测试使用单独的临时用户目录，只关闭测试创建的实例；未关闭用户原会话。测试只读取布局结构、媒体状态与固定数值，不读取聊天文本。

限制：Intel 没有实机测试；macOS 13–25 没有实机测试；没有 Apple Developer ID 公证；无法承诺任意未来客户端布局都兼容。界面捕获工具在本机会报截图错误，因此没有将窗口截图作为渲染验收；首帧呈现和视频播放证据来自播放器与官方客户端渲染器状态。
