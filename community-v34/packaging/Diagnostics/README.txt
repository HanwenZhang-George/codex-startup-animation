轻量诊断工具（正式版也保留）

发生问题时双击 One-Click-Diagnostics.cmd。
固定输出：
  Diagnostics\Reports\latest-report.zip    发回给维护者的报告
  Diagnostics\Reports\latest-analysis.txt  自己查看的中文分析
每次更新最新一份，不堆积历史 ZIP。要保留历史，请自行另存上一份。

默认不做完整媒体哈希、不运行显卡/CPU 压力测试、不启动或关闭任何应用；
只读取有限日志、已注册官方客户端的固定兼容标记和六段视频的存在性/大小。
不下载东西、不联网、不安装依赖、不扫描全盘、不读取账号配置/聊天/进程命令行。
报告只输出允许的数值、枚举和标记，不导出原始日志、真实路径或 API Key。
中文分析是基于现有日志的判断，不会把旧记录冒充当前状态或承诺不存在其他问题。
大部分情况下几秒内完成；慢磁盘和系统 I/O 可能延长。Ctrl+C 可结束工具。

如果怀疑解压缺文件，双击 Check-All-Files.cmd 做完整 SHA-256 校验。
它顺序读取包内文件，不解码视频、不跑显卡，校验结果保存在 Reports\file-check.json。
完成后再双击 One-Click-Diagnostics.cmd，即可把校验摘要纳入同一报告。
工具脚本本身很小，图像视频素材才是这个包的主要体积；不会额外生成视频或截图。

首次测试建议：
1. 完整解压到新文件夹，运行完整文件校验。
2. 保存工作并正常完整退出 Codex，再双击上一级的 Launch.exe。
   未绑定的官方图标会绕过本便携包。可选安装绑定成功后，应在安装目录收集报告。
3. 观察启动、眨眼、流泪、波纹、常态壁纸。卡住时可按 ESC，立即生成报告。
4. 切换/新建对话、展开侧栏、调整大小、最大化/最小化恢复，检查输入框与按钮。
5. 打开 WallpaperControls.exe，暂停再恢复。
6. 由本包启动 Codex 后，再点击一次 Launch.exe，检查重复启动处理。
   原窗口应继续使用，壁纸保留；识别失败会提示收集报告，不会强制重启 Codex。
7. 完整退出后再启动一次，按 ESC，检查进入 Codex 后的壁纸。
8. 有余力再测试系统重启后第一次启动，不需要跑长时间压力实验。
9. 最后生成报告，并补充在哪一步出问题、是否卡顿、是否出现黑框。

正常轮播：第一次常态；以后每次 75% 常态、25% 粒子。
角色两次出现之间有原有 10–15 秒间隔；不是每四次必定出现一次粒子。
普通方式已运行的 Codex 无法补接私有管道：请完整退出，再从本包 Launch.exe 启动。
未知运行时标记不等于已确认 Tauri，也不等于本包已实现对应通信适配。
不用在用户电脑运行 source/tests 开发回归；这些是给开发者的测试源码。

官方更新后的 R10 适配检查：
1. 从新解压目录的 Launch.exe 启动。普通版本号或安装路径变化会重新读取
   Windows 当前用户注册信息，并核对官方签名；不需要手改官方 EXE 哈希。
2. 如仍没有壁纸，直接生成报告；工具只摘录识别策略的版本/模式/旧固定字段
   是否存在及固定身份验证结果，不导出原始配置、进程身份或安装路径。
3. 配置存在、签名验证通过、客户端已经启动，都不单独代表壁纸播放成功。
   若官方更换包标识、签名身份、界面结构或底层框架，仍可能需要新的适配。
